# Shimaa Khaled — Software Engineer & Flutter Developer Portfolio

A modern, production-grade personal portfolio website built with **Next.js 16 (App Router)**, **TypeScript**, and **Tailwind CSS**.

---

## 🌟 Highlights & Features

- **Dynamic Hero Section**: Interactive mobile phone frame showcasing live app switches between **CaloGram (AI)**, **WeDo (SaaS)**, and **Cairo Metro (Transit)** with key metrics and badges.
- **Deep-Dive Case Studies**: Modal views detailing problem statements, engineered solutions, Clean Architecture diagrams (Domain, Data, Presentation), and full-fidelity UI screenshot galleries.
- **Graduation Project Video Showcase**: Video demo integration for **Trivio (Football Social Platform)** with custom playback modal.
- **Theme Switching**: Seamless Light / Dark mode toggle with persistent local storage.
- **Interactive Certificate Lightbox**: High-resolution credential inspector for ITI (120h), DEPI, InnovEgypt (TIEC ITIDA), Udemy Clean Architecture, and Microsoft Learn.
- **Online Curriculum Vitae / Resume**: Interactive ATS-friendly CV viewer with instant print / PDF export and text copy buttons.
- **Interactive Contact Form**: Comprehensive form with client-side validation, error handling, direct copy shortcuts, and email client fallback.
- **Full SEO & Performance Optimization**: Custom metadata, OpenGraph tags, responsive typography, and zero layout shift.

---

## 🚀 Tech Stack

- **Framework:** Next.js 16.3 (App Router with Turbopack)
- **Language:** TypeScript 5
- **Styling:** Tailwind CSS v4 with custom dark mode variants and glassmorphism
- **Icons:** Lucide React & custom brand SVGs (Flutter, GitHub, LinkedIn)
- **Deployment Ready:** Vercel, Netlify, or any Node.js hosting platform

## 🛠️ Local Development

1. **Clone the repository:**
   ```bash
   git clone https://github.com/shimaakhaled1410-hue/portfolio.git
   cd portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```

4. **Build for production:**
   ```bash
   npm run build
   npm run start
   ```
